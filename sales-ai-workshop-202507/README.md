## 営業前調査と提案方針プロンプト

```text
私は営業担当者です。
　顧客の課題を解決する新しいサービスの提案を考えています。
　以下の情報に基づき、提案書の「骨子」となるアイデアを3つ、箇条書きで提案してください。

# 顧客情報
- 業界：保育業界
- 課題：保育士の採用が難しく、採用後の定着率の低さにも悩んでいる。特に、有資格者の確保や若手保育士の早期離職が深刻な課題となっている。

# 自社サービス
- 保育士のための転職・就職支援サービス
- 保育施設向けのICT支援システム
```

### 出力例

※回答ごとに文面は変わるので、参考程度にしてください。

```text
1️⃣ 「若手保育士定着支援パッケージ」の提供
・貴施設のICT支援システムを活用し、若手保育士の業務負担軽減・成長支援を仕組み化（例：日誌・保護者対応の時間短縮、研修動画配信機能追加）
・定着率向上をKPIとした運用コンサルティングをパッケージ化し、離職率改善を数値で示す提案へ昇華

2️⃣ 「有資格者特化型スカウト代行サービス」
・自社転職支援サービスを活用し、有資格者の母集団形成とスカウト送信代行を実施
・地場・他業種からの潜在層へのアプローチを強化し、応募数・面接設定数を保証するプランで提案
・採用広報（動画・SNS投稿支援）も組み合わせ、施設魅力訴求と採用効率化を同時に支援

3️⃣ 「採用・定着データ可視化ダッシュボード」
・採用〜定着までのデータ（応募数、面接率、定着率、離職理由、ICT活用状況）を一元管理するダッシュボード機能をICT支援システムへ追加提案
・定着率の改善ポイントを見える化し、具体的な打ち手（OJT設計、面談頻度、評価基準の改善など）を提案可能にすることで、単なるシステム提供から課題解決型サービスへ進化
```
