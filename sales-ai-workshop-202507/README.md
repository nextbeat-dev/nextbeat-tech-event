## 営業前調査と提案方針プロンプト

```text
私は営業担当者です。
    顧客の課題を解決する新しいサービスの提案を考えています。
    以下の情報に基づき、提案書の「骨子」となるアイデアを3つ、箇条書きで提案してください。
    
    # 顧客情報
    - 業界：飲食チェーン
    - 課題：アルバイトスタッフの採用難と、採用後の定着率の低さに悩んでいる。特に地方店舗での人手不足が深刻。
    
    # 自社サービス
    - アルバイト採用に特化した求人媒体
    - 採用後のスタッフ向けオンライン研修サービス
```

### 出力例

※回答ごとに文面は変わるので、参考程度にしてください。

```text
1️⃣ 地方店舗限定のスカウト型採用強化パックの提案
・自社求人媒体のスカウト機能を活用し、地方店舗向けに絞ったターゲティング配信を実施
・エリア別の応募データ・採用成功事例を活用し、最適な募集条件・時間帯・原稿内容を一緒に再設計
・「応募0のまま掲載終了」を防ぐための週次フォロー体制をセットで提供

2️⃣ 採用後の離職防止を目的とした「オンライン即日研修＆定着サポートパック」
・採用決定当日に即時アクセス可能なオンライン研修を提供し、初出勤前の不安を軽減
・飲食店向け接客・衛生研修コンテンツの短時間版を準備し、地方でも研修コスト・時間をかけずに実施可能
・研修受講データを店舗責任者へレポートすることで、定着率向上施策の一環として活用可能

3️⃣ 「採用×定着」同時支援の定額サブスクリプションモデルの提案
・地方店舗ごとの採用枠（求人媒体利用）＋オンライン研修のセットを月額固定で提供
・繁忙期・閑散期問わず求人掲載と研修活用が可能で予算平準化を実現
・毎月採用・定着状況を報告し、課題店舗へは追加施策（原稿修正・研修強化）の提案を随時行う運用型支援
```
